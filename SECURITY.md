# Security Policy

## Supported Versions

This project is currently in the POC stage. Use with caution.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | not yeat released |

## Reporting a Vulnerability

Create an issue under https://github.com/owaspcornucopia/ThreatSutra/issues
Please consider the current [threat model](https://github.com/owaspcornucopia/ThreatSutra/tree/main/ThreatDragonModels) when reporting. 
Certain security issues might not be applicable considering how the application is intended to be used.
